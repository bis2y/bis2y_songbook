# ✦ BIS2Y SONG BOOK ✦

화이트 + RGB(160, 160, 255) 라벤더 테마의 반응형 노래책 사이트입니다.

## 신청 안내

- 일반 신청곡: **3,000 치즈**
- 원하는 노래 연습해오기: **30,000 치즈**
- 언어 이슈 및 높은 음정 등으로 너무 어려운 노래는 제외될 수 있습니다.

## 노래 추가 방법

1. `manage.html`을 엽니다.
2. 곡 제목, 가수, 장르를 입력합니다.
3. 추천곡이면 `추천곡`, 신곡 영역에 노출하려면 `신곡`을 체크합니다.
4. `songs.js 내려받기`를 누릅니다.
5. 내려받은 파일로 기존 `songs.js`를 교체한 뒤 다시 배포합니다.

`신곡`으로 체크한 노래는 홈 상단의 **✦ NEW SONGS ✦ / 신곡 추가** 영역에 한 번 더 표시되고, 전체 노래 목록에도 `✦ NEW` 배지가 붙습니다.

## CSV 형식

```csv
title,artist,genre,recommended,isNew
밤편지,아이유,발라드,true,true
Lemon,요네즈 켄시,J-POP,false,false
```

## 미리보기

`index.html`을 바로 열거나 아래 명령어로 로컬 서버를 실행하세요.

